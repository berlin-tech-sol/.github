# Berlin Tech Sol

**AI Agents, CRM Automation, Full-Stack Development and DevOps**

Berlin Techs is a software development agency based in Munich, Germany, that helps businesses automate everyday tasks and build reliable software.

We develop AI agents, CRM automations, API integrations, and custom web applications. Our team has practical experience with ServiceNow, Jira, Odoo, Python, React, Node.js, and Next.js.

We also handle cloud migration, server administration, and DevOps — moving workloads to AWS, Azure, and GCP, setting up CI/CD pipelines, and keeping servers running so your team isn't stuck babysitting uptime. This side of the work draws on Docker, Kubernetes, Terraform, and Linux server administration, backed by monitoring through tools like Grafana and Prometheus.
