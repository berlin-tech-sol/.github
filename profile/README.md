### 👋 About us

Berlin Techs is a software development agency based in Munich, Germany, that helps businesses automate everyday tasks and build reliable software.

We develop AI agents, CRM automations, API integrations, and custom web applications. We also handle cloud migration, server administration, and DevOps — moving workloads to AWS, Azure, and GCP, setting up CI/CD pipelines, and keeping servers running so your team isn't stuck babysitting uptime.

### 🧭 How we work

Before starting a project, we take time to understand your current process, the tools you are using, and the result you want. We then break the project into clear milestones and provide regular updates as work progresses.

Our previous work includes a ServiceNow/Jira proof-of-concept integration, a hotel booking platform with Stripe, CRM workflow projects, and AI systems for customer support and lead qualification.
